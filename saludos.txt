Hola desde Git

Pregunta 1:¿Para qué sirve el comando git status?
Respuesta: Muestra el estado del directorio de trabajo y del área de preparación , Permite ver qué archivos han sido modificados, cuáles están listos para un commit y cuáles no están siendo rastreados por Git.

Pregunta 2: ¿Cuál es la diferencia entre git add y git commit?
git add selecciona y prepara los cambios (los pone en la sala de espera), mientras que git commit los guarda permanentemente en el historial.

Pregunta 3: ¿Qué diferencia hay entre git pull y git fetch?
git fetch solo descarga las novedades del repositorio remoto sin alterar tu código, mientras que git pull descarga las novedades y las mezcla (hace un merge) automáticamente en tus archivos locales.

Pregunta 4: ¿Para qué sirve git branch y por qué es útil trabajar con ramas?
git branch sirve para crear, listar o eliminar ramas. Es útil porque te permite crear líneas de trabajo independientes para desarrollar funciones o corregir errores sin alterar el código principal y estable del proyecto.

Pregunta 5: ¿Qué es un conflicto de fusión (merge conflict) y cómo se resuelve?
Un conflicto de fusión se prodice cuando git no puede decidir automáticamente qué cambios conservar porque dos personas modificaron la misma línea del mismo archivo, o porque alguien borró un archivo que otra persona editó.
